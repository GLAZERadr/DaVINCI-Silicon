## P2: failure triage, "is it the design or the test?" (~2–3 h, only after P0+P1)

Engineers spend time deciding whether a failure is in the RTL or in the testbench/model. DaVINCI can answer part of this honestly from data it already has.

- For every failing test in an attempt, show a test credibility line built only from measured data: passes on the hand-written reference RTL? (with suite hash) · planted bugs this test kills alone / together (`mutation.json`) · covered scenarios it drives.
- Measured verdict label: test validated on reference RTL and kills ≥1 mutant → `Test validated · failure points to the design under test`; test not validated (e.g. tests derived from a new spec intake, not yet run on a reference) → `Test not yet validated · check the test before the design`.
- Label it measured (computed, not AI text). The AI diagnosis stays separate and dashed.
- Done when: live02-m1 attempt 1 shows both failing tests as validated, with their killed mutants, and a spec-intake-only run would show "not yet validated".
